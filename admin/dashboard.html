Publish Perubahan

Draft di browser ini belum kelihatan oleh pengunjung lain sampai kamu publish salah satu cara di bawah.

Cara 1 — Download & Upload Manual (paling aman)

Download file-nya, lalu upload/replace ke repo GitHub kamu (drag & drop di halaman repo, commit). GitHub Pages otomatis update dalam 1–2 menit.

Cara 2 — Publish Langsung ke GitHub (opsional, lebih cepat)

Fitur ini butuh GitHub Personal Access Token dengan akses tulis ke repo kamu. Token ini HANYA dipakai di browser kamu sekarang (tidak disimpan permanen, hilang setelah tutup tab) — tapi tetap jangan share token ke siapapun. Pakai token yang scope-nya dibatasi ke repo ini saja kalau bisa.
